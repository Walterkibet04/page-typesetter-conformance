`/app/folio.py` is our page typesetter. It reads a `.fol` document and lays it out on pages: heading placement, line breaking with hyphenation, justification, drop caps, footnotes at the foot of the page, page references, and the rules for splitting paragraphs across pages. The program is a first draft: it reads the format and writes the output format, but its layout rules are placeholders. `/app/spec.txt` describes the house style in general terms. `/app/folio_ref` is the reference build of our typesetter: `/app/folio_ref file.fol` prints the correct output for any document. Make `/app/folio.py` produce exactly the output of `folio_ref` for any valid document. Treat `folio_ref` as a black box: run it, but do not take it apart or copy it into your solution.

`typeset(text)` returns the result as a dictionary and running `python3 /app/folio.py file.fol` prints it as JSON.
